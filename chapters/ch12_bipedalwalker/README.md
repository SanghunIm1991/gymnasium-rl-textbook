## 学習後（Stable-Baselines3 の PPO で 5,000,000 ステップ学習した、最後の時点のモデル）

ロボットは、左の端の赤い旗のそばから歩き出します。濃い色の脚を前へ大きく振り出し、薄い色の脚は膝を曲げて後ろに残したまま、胴体を上下に傾けながら右へ進みます。1,179 ステップで地面の右の端に着いて、エピソードが終わります。ときどき映る赤い細い線は、距離のセンサー（ライダー）の1本を描いたものです。8 ステップごとの絵を 1 枚 160 ミリ秒で表示しているので、ほぼ描画の速さ（1 秒に 50 ステップ）です。
